# Profile Lens

A minimal React app that displays random user profiles fetched from the [FreeAPI](https://freeapi.app).

## Features

- Browse random user profiles in a clean grid layout
- Paginated results for easy navigation

## Tech Stack

- React
- Vite
- FreeAPI

## Getting Started

```
# install
pnpm install

# run dev server
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
